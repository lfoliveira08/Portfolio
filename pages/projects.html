Controls · PLC & SCADA · ICS Security

CyberCity

Aug – Dec 2026

My solo senior design project (Automated Cyber-Physical Campus System Design): a 3D-printed smart-campus control system and security testbed spanning two buildings, BSH and Founder's Hall. Eight ESP32 field nodes run an elevator, an HVAC unit, fire alarms, access doors and power boxes as Modbus TCP slaves. Each node is controlled by its own OpenPLC runtime in a Docker container, and one Ignition 8.3 gateway supervises all eight PLCs with a Perspective campus-map HMI, heartbeat-based node health, alarming, and cross-system cascade rules, such as a fire-alarm pull station cutting power to the elevator. The layout follows the Purdue Model, and a Kali node on the same network drives the Modbus attack and defence scenarios.

Project RAILROAD

2025–2026

A UIW research-lab testbed that models how threats move laterally from IT networks into safety-critical railroad control. An OpenPLC master on a Raspberry Pi 4B runs IEC 61131-3 ladder logic over ESP32 Modbus TCP slaves for track switches, track power and a radar sensor, alongside Allen-Bradley MicroLogix 1100 PLCs, across two physical layouts: a LEGO loop and an HO-scale track. The team designed ten adversarial scenarios mapped to real CVEs, confirmed physical impact such as unauthorized switch movement and device denial of service, and documented the mitigations, from network segmentation to fail-safe defaults on communication loss. Built for $1,355.

Closed-Loop Control · Embedded · IoT

Automatic Plant Watering System

Fall 2026

Stage 1 of a smart greenhouse, built with Uriel Garcia for ENGR 4399 Cyber-Physical and IoT Systems. An ESP32 reads calibrated soil-moisture and tank-level sensors and drives a pump through a relay using a four-state controller (Idle, Watering, Soaking, Fault) with hysteresis, an 8-second run limit, a soak delay, a response check and a latching fault. A tank-low interlock and a rain block from a live weather forecast keep the pump from running when it shouldn't. Status shows on an OLED screen and on a web dashboard served by the ESP32 itself.
